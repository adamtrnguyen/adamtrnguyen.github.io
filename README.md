# adamtrnguyen.github.io

My academic site, live at **[adamtrnguyen.github.io](https://adamtrnguyen.github.io/)**.

Adam Nguyen. M.S. Computer Science at UMD from Fall 2026, B.S. Computer Science
at Virginia Tech, 2026. Research at the [ReDS Lab](https://reds-lab.github.io/)
on data-centric AI, LLM evaluation, and data selection.

The site holds my CV, publications, news, and project pages.

## Run it locally

```bash
docker compose up          # serves on http://localhost:8080, reloads on save
```

Without Docker:

```bash
bundle install
bundle exec jekyll serve
```
